# GUI View for Editing Open Questions

When an artefact includes open questions, there should be a menu button on the top bar for "Resolve Questions", this will open a modal with a panel for each of the questions.  The user can then go through each question and provide a reponse, then click a next button to continue.

Once all questions have been answered the system should then update the bottom of the markdown file with the questions and the responses and change the heading "Open Questions" to "Resolved Questions" and change the status from Blocked to Draft.
